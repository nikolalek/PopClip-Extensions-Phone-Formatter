Согласно **ГОСТ Р 7.0.97-2016** (и подтвержденным нормам в редакции **2025 года**), написание номеров телефонов в официальных документах (реквизит «Справочные данные об организации») строго регламентировано.

### Общие правила (п. 5.8)

1. **Международный формат:** Номера записываются с использованием кода страны и кода города.
2. **Группировка цифр:** Цифры внутри номера разделяются дефисами или пробелами для читаемости.
3. **Знак «+»:** Обязателен перед кодом страны (например, `+7`).
4. **Скобки:** Код города (зоны) берется в круглые скобки.

---

### Стандартные шаблоны оформления

| Тип номера | Корректная запись (Пример) |
| --- | --- |
| **Городской (Москва)** | `+7 (495) 123-45-67` |
| **Городской (регион)** | `+7 (812) 987-65-43` |
| **Многоканальный** | `+7 (495) 123-45-67 (многоканальный)` |
| **Несколько номеров** | `+7 (495) 123-45-67, +7 (495) 123-45-68` |
| **С добавочным** | `+7 (495) 123-45-67, доб. 123` |

---

### Нюансы форматирования

* **Код страны:** Всегда `+7` для России. Использование `8` в официальной переписке не допускается, так как это код выхода на межгород внутри старых АТС, а не международный формат.
* **Разделители:** Между кодом города и номером ставится пробел. Внутри самого номера используются дефисы: `123-45-67`.
* **Позиция в документе:** Телефон указывается в составе реквизита «Справочные данные об организации» (вместе с почтовым адресом, e-mail и ОКПО). Обычно это верхняя часть бланка (штамп) или нижний колонтитул.
* **Иностранные номера:** Форматируются аналогично, исходя из правил страны (например, `+49` для Германии).

### Рекомендация для macOS / Automation

Логика по ГОСТ должна выглядеть так:
`+7` `[пробел]` `(` `XXX` `)` `[пробел]` `XXX` `-` `XX` `-` `XX`

> **Важно:** ГОСТ Р 7.0.97-2025 делает акцент на том, что данные должны быть пригодны для автоматизированного считывания. Использование скобок для кода города остается обязательным стандартом де-юре.
